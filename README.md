# recipe-finder

Ищет простые рецепты по категории, переписывает их своими словами и собирает готовые статьи с фото в PDF — публикуемо, без нарушения авторских прав.

## Пайплайн

1. **finder** — ищет кандидатов по теме, с предпочтением доверенным источникам (`ru.wikibooks.org`, «Поваренная книга», CC BY-SA).
2. **license-check** — для источников не из доверенного списка ищет явную пометку об открытой лицензии на странице; нет чёткой пометки → кандидат отклоняется.
3. **fetcher** — сохраняет исходный текст и метаданные лицензии в `sources/`.
4. **writer** — переписывает рецепт своими словами.
5. **image-picker** — ищет лицензионно чистое фото блюда на Openverse (Wikimedia и подобные), не с сайта-источника рецепта.
6. **pdf-export** — собирает текст + фото + атрибуцию в `recipes/<название>.md` и `.pdf`.

## Запуск

```
node index.js [количество] "категория рецептов"
```

Пример:

```
node index.js 5 "простые завтраки"
```

Если количество не указано, по умолчанию — 5.

## Результат

- `sources/<рецепт>.json` — архив исходного текста и метаданных лицензии (для отладки/аудита).
- `recipes/<рецепт>.md` и `.pdf` — готовая переписанная статья с атрибуцией текста и фото.

## Требования

- Установленный и авторизованный Claude Code CLI (`claude`).
- Node.js 18+ (нужен глобальный `fetch` для запроса к Openverse API).
